Project Information

This webtool evaluates the AI model of the SenseBox Bike, which classifies the surface the bike rides on. In the first track (April 30), the ground truth was manually adjusted as it was found to be incorrect. The four different surface classes of the SenseBox AI were aggregated into 'nature' and 'paved' to match the official data.

About us

Author: Kevin Kosch
I am a Geomatics Master's student at ETH Zurich and this web app was created as part of my Assignment 3 for the Advanced GIS course. For this task, I tested the provided Bike SenseBox's Surface AI by comparing it to official data from swisstopo. The raw csv data of the sensebox was combined with the ground truth data from swisstopo (mistakes were corrected if I found any) in a preprocessing step with python. After the preprocessing, a GeoJSON file was generated for each track which has been used for visualization.

Privacy

This web application is purely static. It does not collect any personal user data and does not use any tracking or analytics tools. The displayed sensory data tracks are localized to public domains, and personal attributes have been masked to comply with academic privacy standards.
